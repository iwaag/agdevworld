# Discussions

Merged into [conversations.md](conversations.md) (challenge p2): a
discussion is a conversation a conductor leads (*Facilitation*), served by
the same engine, CLI (`wfe conversation`; `wfe discussion` is the same
command) and HTTP tree (`api/conversations`) as every other. Conversations
that began as discussions keep their ids and their archive at
`discussions/<id>/` in pj-ponderer.
